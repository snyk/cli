# Manual allowed words for CLI debug log redaction
#
# This file contains hand-curated words that should NEVER be redacted from debug logs,
# even if they appear as argument or environment variable values.
#
# Format:
#   - One word per line
#   - Lines starting with # are comments
#   - Empty lines are ignored
#   - Words must be lowercase, alphabetic, >= 5 characters
#   - Keep this file sorted alphabetically for easy maintenance
#
# Guidelines for adding words:
#   - Only add words that are common, non-sensitive values
#   - Do NOT add words that could be tokens, IDs, or secrets
#   - Prefer adding words that appear in multiple contexts
#   - Consider whether the word would ever be used as a secret
#
# Categories below are for documentation only - the generator treats all words equally.
